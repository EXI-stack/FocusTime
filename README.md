# ⏳ Focus Time

**Focus Time** — это минималистичный десктопный таймер для концентрации на задачах. Он создан для того, чтобы вы могли спокойно работать и не следить за часами.

Главная особенность приложения — **вы точно не пропустите окончание таймера, даже если отошли от ПК**. Когда время выйдет, программа воспроизведёт мягкий звуковой сигнал, покажет системное уведомление, развернётся поверх остальных окон и **начнёт плавно пульсировать на экране**, пока вы не вернётесь и не кликнете по ней.

### ✨ Основные возможности
* **Режим ожидания вас:** плавная пульсация окна и вывод на передний план по завершении сессии.
* **Удобные пресеты:** быстрый выбор интервалов на `15`, `25`, `45` или `60` минут.
* **Работа в фоне:** приложение можно свернуть в системный трей, чтобы оно не мешало на панели задач.
* **Темы оформления:** приятная светлая и тёмная темы (подстраивается под систему или переключается вручную).
* **Звуковой сигнал:** автоматически генерируемый мягкий звук по окончании времени.

---

### ⌨️ Горячие клавиши
* `Пробел (Space)` — Старт / Пауза / Продолжить
* `R` — Сброс таймера
* `Ctrl + T` — Переключение темы (светлая / тёмная)
